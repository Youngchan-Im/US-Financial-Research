| 열 이름 | 의미 |
|---|---|
| ticker | 거래소에서 쓰는 기업 티커. 예: `AAPL` |
| company_name | 기업의 공식 이름. 예: `Apple Inc.` |
| sector | 기업이 속한 산업 구분. 예: `Technology` |
| reason | 프로젝트 후보로 넣은 이유 |
| data_check | 데이터 수집 가능 여부를 나중에 표시하기 위한 열 |
